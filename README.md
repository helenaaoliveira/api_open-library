# API Open Library

API usada: Open Library Search API
Link: https://openlibrary.org/dev/docs/api/search

O que ela devolve: Assim que digitamos o nome de um livro ou autor e clicamos em "Pesquisar", a API nos devolve informações sobre os livros encontrados, como título, autor, ano da primeira publicação e capa, quando disponível.

O endereço que você chamou:
https://openlibrary.org/search.json?q=(autor/livro)

Como rodar: Abrir o arquivo index.html usando um servidor local, como o Live Server do VS Code, e acessar o endereço no navegador.

Dificuldade: Tivemos dificuldade para implementar a API, fazer a consulta através do JavaScript e mostrar os resultados dos livros na tela de forma organizada.
